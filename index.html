git status

Mostra o estado atual do repositório.

git status

git clone

Clona um repositório remoto.

git clone URL_DO_REPOSITORIO

git add

Adiciona arquivos para o próximo commit.

git add .

git commit

Registra as alterações no repositório.

git commit -m "mensagem"

git push

Envia alterações para o repositório remoto.

git push

git pull

Baixa as alterações do repositório remoto.

git pull

mkdir

cd

Acessa uma pasta pelo terminal.

cd nome-da-pasta

ls

Lista arquivos e pastas.

ls

pwd

Mostra o diretório atual.

pwd

clear

Limpa o terminal.

clear

python

SELECT

Consulta registros de uma tabela.

SELECT * FROM usuarios;

INSERT

Insere um novo registro.

INSERT INTO usuarios VALUES (...);

UPDATE

Atualiza registros existentes.

UPDATE usuarios SET nome = 'João';

DELETE

Remove registros de uma tabela.

DELETE FROM usuarios WHERE id = 1;
